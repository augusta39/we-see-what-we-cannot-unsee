# Protocols

Plans for the two H6 tests in Hippocorpus, written before each run and frozen with a SHA-256 hash.

| Protocol | SHA-256 |
|---|---|
| `protocol_H6_hippocorpus_v1.md` | `03b69a52395bd3451dbc428a65443c14367b8ff8c6963fbbfeda37846b2c9391` |
| `protocol_H6_hippocorpus_v2.md` | `9d97ebee0166951dcc6703ebc6378a462c7d49ddce4b484224bc638f0a00ff5d` |

Check a file against its hash with `sha256sum -c protocol_H6_hippocorpus_v1.sha256`.

These are dated, hashed plans kept alongside the code. They were not filed on a public registry such as OSF or AsPredicted, so they are not a formal preregistration. Each protocol states what had already been looked at in the data before it was frozen.
